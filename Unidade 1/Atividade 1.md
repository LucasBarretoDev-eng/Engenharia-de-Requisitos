# Levantamento de Requisitos do Sistema de Controle de Frequência Escolar

## 1. Quem utilizará o sistema?

- Professores.
- Coordenadores e secretaria da escola.
- Alunos

## 2. Cite 3 requisitos funcionais (o que o sistema deve fazer)

1. Registrar a presença e a falta dos alunos em cada aula.
2. Consultar a frequência de cada aluno por turma e disciplina.
3. Gerar relatórios de frequência para professores e coordenação.

## 3. Cite 2 requisitos não funcionais (como o sistema deve funcionar)

- O sistema deve estar disponível durante o horário de funcionamento da escola.
- O sistema deve garantir a segurança dos dados, permitindo acesso apenas a usuários autorizados.

## 4. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.

O levantamento de requisitos é uma etapa essencial no desenvolvimento de um software, pois permite compreender as necessidades dos usuários e os objetivos do sistema. Com essas informações, a equipe de desenvolvimento consegue planejar melhor as funcionalidades, reduzir erros e evitar retrabalho durante o projeto. Além disso, os requisitos garantem que o sistema final atenda às expectativas da escola, oferecendo uma solução mais eficiente, segura e adequada às atividades do dia a dia.
